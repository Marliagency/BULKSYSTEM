# Bulk System — Brand Guide

## Logo
- Wordmark: "BULK SYSTEM" en Syne 800
- Variante: "BS" en verde neón para avatares y favicons
- Siempre sobre fondo oscuro
- Nunca usar sobre fondos claros

## Colores
| Nombre | Hex | Uso |
|--------|-----|-----|
| Negro principal | `#0A0A0A` | Fondo base |
| Negro secundario | `#111111` | Cards, secciones |
| Verde neón | `#39FF6A` | Acento principal, CTAs |
| Blanco suave | `#F0F0F0` | Texto principal |
| Gris medio | `#888888` | Texto secundario |

## Tipografía
| Rol | Fuente | Pesos |
|-----|--------|-------|
| Display/Títulos | Syne | 700, 800 |
| Cuerpo | DM Sans | 400, 500 |
| Métricas/Datos | JetBrains Mono | 400, 500 |

## Tono de voz
- Cercano pero profesional
- Claro y directo
- Motivador sin ser agresivo
- Enfocado en sistemas, no en motivación

## NO hacer
- Usar colores brillantes secundarios
- Usar lenguaje "gym bro"
- Poner frases motivacionales vacías
- Usar fotos de bodybuilders
- Comparar con otras apps directamente

## Ejemplos de copy correcto
✓ "Sigue el sistema. Los resultados llegan."
✓ "Sin contar calorías. Sin improvisar."
✓ "Tu dashboard lo hace por ti."

## Ejemplos de copy incorrecto
✗ "¡Conviértete en un monstruo del gym!"
✗ "Gana masa muscular BRUTAL"
✗ "La app #1 para hardgainers del mundo"
